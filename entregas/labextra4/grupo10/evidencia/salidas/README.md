# Evidencias de salida — Grupo 10

Guardar aquí las salidas **crudas, sin editar**, obtenidas con redirección desde los comandos realmente ejecutados. No incluir resultados inventados ni transcripciones reconstruidas a mano.

Salidas previstas según la consigna:

- `crack_sin_reglas.txt` — salida real del ataque de diccionario.
- `crack_con_reglas.txt` — salida real del ataque con reglas.
- `loot_operador.txt`, `loot_analista.txt`, `loot_admin.txt` — solo si se ejecutó el descifrado; cada archivo debe corresponder a la salida original.
- `ctf_status_extra4.txt` — salida completa de `./ctf status extra4`.
- `benchmark_*.txt` — mediciones reales, con los comandos, condiciones y cantidad de intentos que permitan interpretarlas.

Los nombres son una propuesta organizativa: si el equipo usa otros, mantener las referencias del informe coherentes con los nombres finales. La evidencia debe corresponder a los comandos registrados en `../comandos.txt`.

No guardar este README como si fuera una salida del laboratorio. Si una salida contiene progreso parcial/interrumpido de PBKDF2, conservarla íntegra y etiquetarla claramente como parcial; no presentarla como búsqueda completa ni como prueba de que la contraseña es irrecuperable.
