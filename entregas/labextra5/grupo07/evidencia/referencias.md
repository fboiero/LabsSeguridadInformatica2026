# Referencias consultadas para P3/P5

- RFC 8725, *JSON Web Token Best Current Practices*:
  https://www.rfc-editor.org/rfc/rfc8725.html
  - §3.1: verificar algoritmo contra una lista permitida.
  - §3.5: entropía suficiente para claves simétricas.
  - §3.8–3.9: validar `sub` y `aud`.
- RFC 7519, §12, consideraciones de privacidad del JWT:
  https://www.rfc-editor.org/rfc/rfc7519.html#section-12
- OWASP API Security Top 10 (2023), API1: Broken Object Level Authorization:
  https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/
