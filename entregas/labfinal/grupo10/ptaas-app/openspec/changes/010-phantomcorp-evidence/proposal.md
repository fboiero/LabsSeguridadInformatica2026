# 010 — Recolección de evidencia de PhantomCorp

El coordinador importa metadatos autorizados de un staging local de confianza y
produce un inventario R1–R4 pendiente de revisión. No conecta con el objetivo,
no genera evidencia de un hito y no otorga créditos. Un hash del original es
una referencia declarada, no se verifica leyendo el archivo original.
